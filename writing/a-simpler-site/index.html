A simpler site

August 2026

My old site was a link directory: a Bootstrap accordion, a 2MB photo, and a button that sent you to a random webpage. It was fun to build and useless to read.

This version is plain HTML and about thirty lines of CSS. No framework, no build step, no dependencies to update. It loads instantly and it will still work in ten years.
